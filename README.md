# AI Career GPS 🚀

AI Career GPS is an AI-powered career guidance platform that analyzes resumes, extracts skills, recommends suitable career paths, identifies skill gaps, calculates job-readiness scores, and generates personalized learning roadmaps.

## Features

✅ Resume Upload (PDF)

✅ Skill Extraction

✅ Career Recommendation

✅ Skill Gap Analysis

✅ Job Readiness Score

✅ Personalized Learning Roadmap

## Tech Stack

* Python
* Streamlit
* PDFPlumber
* Pandas
* Natural Language Processing (NLP)

## Project Workflow

1. Upload Resume (PDF)
2. Extract Resume Text
3. Detect Technical Skills
4. Recommend Career Path
5. Identify Missing Skills
6. Calculate Job Readiness Score
7. Generate Learning Roadmap

## Installation

Clone the repository:

```bash
git clone https://github.com/stuti225/AI-Career-GPS.git
```

Move into the project folder:

```bash
cd AI-Career-GPS
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
